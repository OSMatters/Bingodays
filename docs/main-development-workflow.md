## 每次开发

1. 检查目录、当前分支和未提交文件，避免打开旧工作区。
2. 在本地 main 修改；每个可验证的小功能单独提交。
3. 验证编译、相关自动化测试和实际交互；代码通过与真机通过分开记录。
4. 发布前检查 Release 配置、功能开关、签名、CloudKit 环境及包资源；未经确认不上传、不发布。
5. 多个任务同时工作时避免修改同一文件；先完成并提交一个任务，再开始重叠任务。
