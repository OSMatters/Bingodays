## 4. 界面实际执行轨迹

1. 默认Preview从首页进入盲盒，均未自动弹窗；余额20。点击券余额显示+1领取结果，非会员权益卡显示，连接素材存在。
2. 关闭再点余额，进入“每日限兑1次”兑换页。P=0/T=20，显示已达上限；点禁用按钮无变化。
3. 权益卡进入盲盒付费页，正确显示“解锁更多盲盒位，每天领取更多盲盒券，收获更多开盒惊喜”。点击返回已执行，但转场稳定态未再采集，取消返回只计部分验证。
4. 使用P=200/T=0且日赠已结算的Preview夹具重启。进入Pets首盒N=8，点击随机抽取：弹兑换，显示差1张，数据仍200/0。
5. 点击兑换，获得+1及“明天还可以再兑换1张，继续收集惊喜”“每日凌晨4点刷新”。点“去开盲盒”只关窗，详情仍N=8。
6. 再点余额，P=100/T=1，显示“今日已兑换”及次日提示；禁用按钮点击无变化。
7. 关闭后手动点首位，获得普通pets_01，无闪光；确认后N=7，T=0。
8. 点端盒显示还差7张，P=100/T=0且仍今日已兑换。未发生部分开盒或额外扣分。
9. 已开启2位后查看概率：常规每款9%、隐藏单抽1%、整批9%，不泄露未开款式。
10. 返回首页显示Pets剩余7/9，券0；点My Box时Mac锁屏，测试被中断，没有取得My Box稳定UI，不判通过。

此路径是预览钱包对账，不能替代真实积分流水、真实会员或CloudKit端到端对账。
